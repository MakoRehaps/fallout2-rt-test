# Prefabs and Mined Structure Parts

Reusable construction vocabulary mined from Fallout 1 and Fallout 2 maps and combined into new Fallout 3 classic structures.

Planned categories:
- wall runs/corners
- doors/windows/openings
- floors/roofs
- rooms/hallways
- fences/gates
- rubble/ruin edges
- cave sections
- industrial machinery clusters
- settlement/shack parts
- military/vault parts

Pieces should carry connector metadata so the generator can combine them without broken walls, inaccessible doors or impossible rooms.
