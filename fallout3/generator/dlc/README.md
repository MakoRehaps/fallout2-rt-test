# Fallout 3 Generator DLC Profiles

DLC profiles control which construction libraries the automatic generator is allowed to use and how strongly each source influences generated areas.

Base Fallout 3 should remain visually anchored to Fallout 1/2. Tactics is opt-in for DLC/style profiles.

Profile fields:

- source weights
- preferred structure tags
- excluded tags
- ruin/intact bias
- settlement density multiplier
- military/industrial bias
- subway generation switches

The generator should record the active profile in every output manifest for reproducibility.
