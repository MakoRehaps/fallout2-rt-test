# Subway / Metro Generator

Fallout 3 metro generation for the classic Fallout engine.

The metro is represented as a connected graph of native maps rather than a seamless 3D train simulation.

Planned map families:
- surface metro entrance
- station concourse
- platform
- tunnel straight/curve/junction
- maintenance/service rooms
- collapsed sections
- flooded sections
- hostile encounter sections
- station-to-surface exits

Each metro node will record connections to neighboring underground maps and any linked surface map.
