# Control Maps

Image-driven control data for Fallout 3 classic-map generation.

Planned/generated layers:
- height/topography
- slope
- terrain/biome gradient
- road/path
- build density
- no-build/blocking
- landmark/core
- ruin/damage
- water/flood

These masks guide tile selection, terrain stamping, roads, buildings, rubble and gameplay anchors.
